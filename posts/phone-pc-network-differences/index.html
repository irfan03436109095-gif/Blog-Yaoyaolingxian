同一个机场手机能用、电脑不能用？按设备与网络交叉排查

王牌飞行员2026-09-20— 次阅读
故障排查

手机正常、电脑异常，只能说明两次使用的条件不同，不能马上证明电脑坏了或机场只支持手机。“同一个订阅”也不等于两端正在使用同一节点、同一路由和同一种接入网络。

先对齐四项基础信息

记录手机当前使用 Wi-Fi 还是移动数据，电脑通过什么网络连接。再检查两端实际选中的节点、客户端及内核版本、订阅更新时间。节点别名相同，也应留意是否属于不同分组或已经更新了内容。

如果手机使用自动选择，电脑固定一个节点，应先统一到一个候选节点做短时测试，否则比较的是两组不同条件。

用四组对照缩小范围

测试 观察重点
手机连接家庭 Wi-Fi 与电脑尽量使用同一接入网络
手机切换移动数据 观察接入网络变化后的结果
电脑连接手机热点 尽量保持电脑配置不变，只换网络
电脑在原网络测试另一目标 排除单一目标服务异常

热点测试会使用移动数据，应控制传输量。记录结果即可，不需要长时间跑大文件测速。

如果手机只在移动数据下正常、两台设备在家庭 Wi-Fi 下都异常，优先看家庭网络相关因素；如果手机在同一 Wi-Fi 下正常而电脑始终失败，优先看电脑客户端、接管和配置差异。这是排查方向，不是最终定论。

检查电脑请求是否进入代理

浏览器与其他应用可能采用不同代理设置。测试时查看连接记录：没有相应连接，先检查入口；有连接却走错出口，再查规则；出现认证或配置报错，再查协议与版本。

系统代理与客户端核心路由需要分别理解，不能只看一个开关。v2rayN 官方系统代理与路由说明

IPv6 和 DNS 是线索，不是万能答案

两台设备可能选择不同地址族或解析路径。mihomo 文档也分别描述了内核 IPv6 与 DNS 中的 IPv6 处理项，所以一个位置的开关不能代表整个系统的行为。全局配置、DNS 配置

如果怀疑相关因素，应记录实际地址族和错误，再用有明确恢复方法的对照测试验证。不要在没有证据时永久关闭整台设备的 IPv6。

提交问题前留下最小证据

写清楚四组对照结果、版本、实际节点和首个错误。若刚升级后出现问题，也记录升级前是否可用。不要把完整订阅或所有日志直接公开。
